## Starter Unit 1 flashcards on Vercel

The actual Hallium website serves `/flashcards` as its own full-screen studio using the same pattern as `/hangul`. The iframe loads `/flashcards-level1/index.html` from `public/flashcards-level1/` in this repository. The 12 Starter words, four visual/recall/listening/sentence learning modes and all semantic illustrations are copied from the GitHub Pages preview. Cards use browser-local state under `hallium:starter-level1:flashcards:v1` on **this hostname**, not Supabase, so Vercel and GitHub Pages do not share progress. The page explicitly states that learning activity is not synced to the learner account. The Book V1 and V2 archived previews are left on GitHub Pages with external links; the independent live Hallium Google login, notes and Study Partners are unchanged. To integrate Supabase progress, make a separate audited migration and explicit learner opt-in.
